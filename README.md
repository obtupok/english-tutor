# Личный репетитор английского

Telegram-бот, который отвечает только тебе (Telegram ID 6712257660). Ему можно писать или отправлять голосовые по-английски. Бот отвечает голосом и текстом, исправляет ошибки, подсказывает новые слова, проводит тест уровня и составляет план занятий.

Бот работает на том же сервере Supabase, что и YomiRead (проект `yxoakverustsnnglzdiy`), как отдельная функция `english-tutor`. С сайтом YomiRead он никак не связан.

## Файлы

- `bot/index.ts` — код бота (функция Supabase).
- `bot/english-tutor.sql` — таблица, где хранятся разговор, режим, уровень и план.

## Запуск (один раз)

1. **Создать бота.** В Telegram открой @BotFather, отправь `/newbot`, придумай имя и username (например, `yomi_english_bot`). BotFather пришлёт токен вида `123456:ABC...`.
2. **Добавить токен в Supabase.** Открой https://supabase.com/dashboard/project/yxoakverustsnnglzdiy/functions/secrets и добавь секрет `TUTOR_BOT_TOKEN`, в значение вставь токен.
3. **Голосовые (по желанию).** Зарегистрируйся на https://console.groq.com (бесплатно), открой API Keys → Create API Key. Добавь секрет `GROQ_API_KEY` с этим ключом. Без него бот понимает только текст, но отвечает голосом всё равно.
4. **Таблица.** В SQL Editor (https://supabase.com/dashboard/project/yxoakverustsnnglzdiy/sql/new) выполни `bot/english-tutor.sql`.
5. **Функция.** Edge Functions → Deploy a new function → Via Editor, имя `english-tutor`, вставь `bot/index.ts` и нажми Deploy. В настройках функции выключи «Verify JWT».
6. **Подключить бота.** Открой https://yxoakverustsnnglzdiy.supabase.co/functions/v1/english-tutor?setup=1. В ответе должно быть `"webhook":{"ok":true...}` и имя бота.
7. Напиши боту `/start`.

## Как пользоваться

Кнопки внизу экрана:
- 💬 **Разговор** — болтовня на любые темы.
- 🎯 **Тест уровня** — 6 вопросов, после них уровень (A1–C2) и план.
- 🧭 **Как учить** — бот расспросит о целях и времени и составит личный план.
- 🎭 **Сценарии** — кафе, аэропорт, отель, магазин, врач, собеседование, «как пройти», разговор про игры.
- 📋 **Мой план** — сохранённый план.
- 🔄 **Заново** — начать разговор в этом режиме с начала.
- 🔊 / 🔇 — отвечать голосом или только текстом.

Можно спрашивать и по-русски: «как сказать…», «что значит…». Под ответом бота есть кнопка «🌐 Перевод».

## Модель

Модель задаётся строкой `MODEL` в `bot/index.ts`. Сейчас там Claude Opus 5.5, это примерно $0.01 за сообщение. Если поменять на `claude-haiku-5-5`, будет в ~40 раз дешевле. После замены функцию нужно задеплоить заново.
